# 端到端模型：损失设计、连续训练与比赛评估完整规划

版本：2026 年 10 月 9 日。主要执行者：C（目标与评估）；协作者：A（数据与编码）、B（主干与训练）。本文为实现与实验计划，不表示所有功能已完成。依据公开参考模板、团队提供的新手指导和保密协议，不读取真实赛事数据。

## 1. 目标与已知边界

在合法决策时点 t，读取股票 i 当时已可见的历史行情与盘口 X，输出一个标量 s，预测官方未来 30 分钟 VWAP 收益标签 y。提交 date 表示决策时点，不是未来窗口结束时点。

$$s_{i,t}=f_\theta(X_{i,\le t}),\qquad y_{i,t}=\text{官方 vwap_return 标签}$$

官方模板用 10 个原始字段、最近 64 条分钟记录、线性输入投影、Transformer、均值池化和回归头，使用 MSE。64 是演示窗口长度；预测期限为比赛规定的未来 30 分钟。VWAP 标签的窗口端点、单位、跨午休和跨日处理待核实，第一版直接使用官方标签。

第一版将 s 视为收益回归估计，不加 sigmoid；它不是上涨概率。采用排序目标后，输出仍可用于表示相对强弱，但收益幅度解释需重新验证。模型不输出实际账户指令，也不以 30 分钟预测期限强制清仓。

比赛评估包括 IC 均值、IC_IR、多空夏普、压力场景稳定性和换手。平台还会去极值、标准化及 BARRA 风格剔除。因此以固定样本外区间的官方表现选择模型，训练损失仅是学习工具。尚未获得官方最终评分权重，不自行创造总分。

## 2. 五类指标与损失的层次

| 项目 | 使用的数据范围 | 当前训练用途 |
| --- | --- | --- |
| 单时点 IC / RankIC | 同一时点多只股票 | 用回归、排序或相关损失改善预测关系 |
| IC 均值 | 多个时点的 IC | 验证期报告与模型选择 |
| IC_IR | IC 时间序列的均值和波动 | 先做长期验证，不直接优化短 batch 比值 |
| 多空夏普 | 组合收益时间序列 | 先评估，明确组合规则后再研究可微目标 |
| 换手 | 相邻调仓时点的对齐持仓 | 先诊断，再加入可微近似约束 |
| 压力稳定性 | 官方指定的困难区间 | 分组验证；定义明确后研究场景加权 |

这些不是五项可直接相加的单样本损失。截面指标、跨时间统计和组合指标具有不同依赖。损失代理是否有效必须通过实验验证。

### 2.1 研究版公式

$$IC_t=\frac{\sum_i(s_{i,t}-\bar s_t)(y_{i,t}-\bar y_t)}{\sqrt{\sum_i(s_{i,t}-\bar s_t)^2}\sqrt{\sum_i(y_{i,t}-\bar y_t)^2}}$$

其中 i 为同一时点的有效股票，横线表示截面均值。RankIC 先将 s、y 转为排名再计算相关。常数截面或样本不足时返回未定义值，单独统计数量，不静默填成零。

$$\overline{IC}=\operatorname{mean}_t(IC_t),\qquad IC\_IR=\overline{IC}/\operatorname{std}_t(IC_t)$$

$$r_t=\sum_iw_{i,t}y_{i,t},\qquad Sharpe=\frac{\operatorname{mean}(r_t)}{\operatorname{std}(r_t)}$$

以上夏普为未年化、未计成本的研究近似。官方收益聚合、无风险收益、成本和年化规则未确定前，不声称复制官方夏普；VWAP 标签也不能自动视作真实账户可实现收益。

$$Turnover_t=\frac12\sum_i|w_{i,t}-w_{i,t-1}|$$

t-1 表示上一个调仓时点，不一定是前一分钟。权重由过去的分数经固定规则产生并保存，不需要模型把过去权重作为输入。研究版明确忽略持仓漂移；真实漂移用上一调仓点到当前点已发生的收益计算，不用当前未来标签替代。

压力场景常见例子是剧烈下跌、高波动或流动性紧张；这些不是已确认的比赛场景。市场下跌不自动意味着多空信号失效。稳定性观察困难区间的预测和组合表现，不是要求分数恒定。

## 3. 共同基线与架构边界

先建立两条记录清楚的基线：官方模板复现版，以及团队模块化版。模块化版采用分组输入 MLP、小 GRU、最后有效状态池化及单标量回归头。对比二者时不能把 encoder、主干和损失同时变化的效果归因于单一模块。

损失研究期间冻结一个输入配置与主干，避免与架构实验混杂。架构研究期间固定目标及数据切分。历史窗口候选为 32、64、120 条有效分钟记录，先用 64 接通；实际可见时间、缺失和时间间隔由 A 处理。

当前先做逐股票时序预测。联合训练 encoder、主干和头；不缓存学习后 token 来代替 encoder 训练。不新增持仓决策网络，也不要求输出整段未来价格路径。

## 4. 数据、batch 与接口

### 4.1 单截面 / 多截面预测 batch

```python
# M 为 batch 中有效样本总数，L 为历史长度，F 为字段数
batch = {
    "x": ...,             # float32 [M,L,F]
    "observed": ...,      # bool [M,L,F], True = 观测有效
    "decision_id": ...,   # int64 [M], 同一时点必须相同
    "instrument_id": ..., # [M], 股票标识，不默认作为模型 embedding
    "target": ...,        # float32 [M], 仅训练/评估使用
    "target_valid": ...,  # bool [M]
}
scores = model(batch["x"], batch["observed"])  # [M]
loss, components = objective(scores, batch, objective_cfg)
```

上述 objective 为拟定的新接口；现有 `score_loss(scores, target, times, ...)` 是起点。输出 components 包含每项损失、有效时点数、有效股票对数和跳过原因。metadata 的顺序必须和模型输出一致。

排序只在同一 decision_id 内计算。先对每个时点计算平均损失，再对时点求平均，避免股票多的时点自动获得更多权重。独立股票随机 batch 可用于回归基线，但不适合作为截面排序的默认采样。

### 4.2 连续时点 batch

K 个相邻决策时点、N 个对齐股票的概念形状为：

$$X\in\mathbb R^{K\times N\times L\times F},\qquad S,Y\in\mathbb R^{K\times N}$$

实现可继续用上述展平接口，再按时点与股票重建对齐矩阵。模型各自读取截至相应时点的历史；K 是训练组织方式，L 是每次预测的历史长度，两者不同。

新增 `transition_valid[K-1]` 指明是否为合法相邻调仓点；配置明确午休、跨日是否计算换手。数据打乱后的相邻 batch 不代表相邻时间。权重计算不能按标签是否存在筛选股票，否则未来标签缺失会改变组合；标签掩码只用于损失和收益评估。

新增、退出、停牌与缺失股票的权重处理必须写清。不同股票子集构造的权重不等于全股票池权重。先在固定小股票集验证对接，真实研究优先覆盖完整截面；若资源不足，明确子集近似，最后用全池评估确认。

K 候选从 2、4 开始，N 按资源选择。K×N×L 的历史重复会扩大内存，B 负责分块推理和等价梯度累积方案；不能为了拆块把跨股票的归一化随意改成块内计算。

## 5. 第一阶段：收益回归与截面排序

### 5.1 MSE 与 Huber

$$L_{MSE}=\operatorname{mean}_{k,i}(s_{i,k}-y_{i,k})^2$$

$$\ell_\delta(e)=\begin{cases}\frac12e^2,&|e|\le\delta\\\delta(|e|-\frac12\delta),&|e|>\delta\end{cases}$$

Huber 在小误差区域使用平方惩罚，在大误差区域使用线性惩罚。它是否优于 MSE 取决于标签尺度与极端样本，不保证更高比赛成绩。

特别注意：若收益标签是 0.001 量级，现有默认 `huber_delta=1.0` 很可能几乎全部处于平方区间。必须报告标签单位和训练区间尺度。可使用仅训练集拟合的固定尺度 a，使模型预测 q=y/a；回归误差按 q 计算，导出时 s=a*q。a 随检查点保存，不使用验证统计重新拟合。该方案是显式实验配置，不强制所有实验使用。

### 5.2 排序损失

$$q_{ij,k}=\operatorname{sign}(y_{i,k}-y_{j,k}),\quad
L_{rank,k}=\operatorname{mean}_{(i,j)\in P_k}\operatorname{softplus}\left(-q_{ij,k}\frac{s_{i,k}-s_{j,k}}{\tau_r}\right)$$

P_k 仅包含同一时点、标签有效且收益差超过阈值的股票对。完全并列跳过；收益差阈值使用记录清楚的标签单位。限制股票对数量并固定抽样随机种子；大截面应直接采样配对，避免先生成全部 O(N²) 对再截断。

$$L_{pred}=\frac1K\sum_k(L_{Huber,k}+\lambda_rL_{rank,k})$$

回归小数尺度和排序 O(1) 尺度可能不同；温度 tau_r、lambda_r、标签缩放共同决定梯度。记录 encoder/主干的梯度范数和损失分量，先做小范围搜索，不直接套用任意等权相加。

输出含义：纯回归保持收益估计解释；混合目标主要验证排序与官方表现，不能仅凭训练标签宣称收益校准仍准确。

## 6. 第二阶段：从分数到权重，再研究换手约束

### 6.1 先实现固定评估规则

研究版采用明确配置的分位数组合：高分组等权做多、低分组等权做空；记录组比例、并列边界处理、每侧敞口、空组处理及调仓时点。配置先固定，不按验证结果反复调组合规则。

例如每侧敞口 0.5，n_top 个多头各权重 0.5/n_top，n_bottom 个空头各权重 -0.5/n_bottom。总净敞口为零，总绝对敞口为 1。不同敞口约定会改变换手数值，必须统一。

保存每期股票权重矩阵后，按同一股票轴计算 Half-L1 换手；第一期建仓成本是否计入单列配置。官方规则明确后另建适配器，保留研究版口径名称。

### 6.2 可微近似仅用于训练研究

硬排序、截断选股不能方便地直接求导。可研究中心化分数的连续权重：

$$c_{i,k}=s_{i,k}-\bar s_k,\qquad w^{soft}_{i,k}=\frac{c_{i,k}}{\max(\sum_j|c_{j,k}|,\epsilon)}$$

有效股票内计算均值和归一化；无效股票置零。非退化截面净敞口为零、绝对敞口为 1。该近似不同于等权选股；近常数截面梯度和敞口可能不稳定，必须诊断。公式也没有复制官方风格剔除。

$$L_{turn}=\operatorname{mean}_{k:\,transition\_valid_k}\frac12\sum_i|w^{soft}_{i,k}-w^{soft}_{i,k-1}|$$

$$L=L_{pred}+\lambda_tL_{turn}$$

这个约束偏好持仓连续，不是要求收益标签连续。不能把相邻未来收益不同本身当成模型错误。lambda_t 太大可能产生固定排序或常数输出；必须同时记录 score 方差、软敞口、官方 IC 和硬组合换手。预测能力明显损失时不保留该方案。

先做 lambda_t=0 的连续 batch 对照，再加非零约束，分离采样方式变化与损失变化。边界及掩码未对齐前不启用此项。

## 7. 第三阶段：跨时间稳定性与压力评估

先在完整验证区间报告 IC 序列、IC_IR、组合收益、夏普、回撤、换手和覆盖率。按年份/月份等预先约定分组检查；官方压力场景未明确时，研究分组只标为代理，不称官方压力得分。

场景可按预先定义的日期或历史可见市场状态划分。训练采样、归一化或模型输入不能使用未来标签定义的状态。按实际事后跌幅做评估切片可以作为诊断，但不能把该状态直接塞进当时模型输入。

初期优化方向：场景均衡采样、训练期多年份覆盖、适度正则和按多个验证阶段选择稳健候选。场景加权损失研究时记录每个组的样本量，不让极小场景主导梯度。

直接优化短 batch 的 IC_IR 或夏普比值仅列为后续候选：分母接近零、时间相关、小样本噪声和官方口径不一致都可能造成不稳定。没有可靠收益定义与足够时间跨度时，不进入主线。

6. 模板声称私榜重训及仅文本权重限制，指导未明确确认；重训数据、接口、时间预算与文件限制需书面核实。

## 12. 数据协作与提交边界

依据提供的保密协议，每名队员各自签署、从本人授权账号获取数据；不因同队共享真实文件或样本。真实数据、非公开字典、受限日志和派生内容不上传 GitHub，包括私有仓库。云端 Agent 使用公开模板、代码和完全人工构造的接口示例；第三方接触数据按协议取得事前书面批准。

模型与数据处理定义由共享代码统一；推理 Notebook 通过 datasources 获取评测表，加载完整参数，输出规定区间内的 date、instrument、factor。只提交一个 Notebook，附上完整脚本、配置、种子和权重；不依赖外网，满足三小时运行约束。受限权重仅按规则提交指定赛事环境，不作为公开仓库附件。

最终交付目标：一套可解释损失、一条可复现训练管线、一份明确区分研究/官方口径的报告，以及一个经平台运行确认的有效候选。
